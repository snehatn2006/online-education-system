# Online Education System - Project Progress

## Problem
Students need a convenient platform to attend online classes, access study materials, submit assignments, and communicate with teachers.

## Project Goal
To develop an online education platform that makes learning easier and provides students with access to courses, classes, study materials, assignments, and progress tracking.

## Completed
- Problem identified
- Main users identified
- Basic requirements identified
- Student login planned
- Student dashboard planned
- Online classes planned
- Study materials planned
- Assignment submission planned
- Teacher-student communication planned
- Student progress tracking planned
- Storyboard created
